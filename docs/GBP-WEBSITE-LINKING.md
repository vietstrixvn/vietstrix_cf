## ✅ Step-by-Step Guide:

### 1. Link Website to GBP (REQUIRED)

**Go to GBP Dashboard:**
```
URL: https://business.google.com
Login: Your Google account
```

**Add Website URL:**
```
1. Select: Vietstrix business profile
2. Click: "Edit profile" (✏️ pencil icon)
3. Navigate to: "Contact" section
4. Field: "Website"
5. Enter: https://www.vietstrix.com
6. Click: "Save"
```

**Add Appointment Link (Optional but recommended):**
```
Still in "Contact" section:
1. Field: "Appointment link"
2. Enter: https://www.vietstrix.com/contact-us
3. Click: "Save"
```

**Verify:**
```
Google search: "Vietstrix"
→ Should see [Website] button in business card
→ Click it → Should go to https://www.vietstrix.com
```

---

### 2. Link GSC with GBP (AUTOMATIC - No Action Needed!)

**Good news:** GSC ↔ GBP linking happens automatically when:
- ✅ Website verified on Search Console
- ✅ Website URL added to GBP
- ✅ Same Google account owns both

**No "Add association" button needed!**

**Verification (after 24-48 hours):**
```
1. Go to: https://business.google.com
2. Select: Vietstrix → Insights
3. Check: "How customers search for your business"
4. If you see search queries → ✅ Linked!
```

**Alternative manual method (if needed):**
```
1. GBP Dashboard: https://business.google.com
2. Select: Vietstrix profile
3. Settings → "Verify this business"
4. Method: Choose "Search Console"
5. Follow prompts
```

**Verify in Search Console:**
```
1. GSC → Performance
2. Filter: "Search type"
3. Look for: "Discover" or location-based filters
4. If available → ✅ GBP data accessible
```

## ⚠️ Common Mistakes to Avoid:

### ❌ Don't:
- Use different URLs in GBP vs website (e.g., www vs non-www)
- Add tracking parameters to GBP URL (use clean URL)
- Forget to verify the link works
- Link to a 404 page or redirect

### ✅ Do:
- Use canonical URL: `https://www.vietstrix.com`
- Test the link in incognito mode
- Keep appointment link to high-intent page (contact-us)
- Monitor GBP insights weekly
